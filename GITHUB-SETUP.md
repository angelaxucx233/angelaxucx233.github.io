# Publishing Your Blog to GitHub Pages

Follow these steps once and your site will be live at **https://angelaxucx233.github.io**

---

## Step 1 — Create the Repository

1. Go to [github.com/new](https://github.com/new) (log in as angelaxucx233)
2. Set the repository name to exactly: **`angelaxucx233.github.io`**
3. Set it to **Public**
4. Leave everything else as default
5. Click **Create repository**

---

## Step 2 — Upload Your Files

On the new (empty) repository page, click **"uploading an existing file"**

Drag and drop ALL files from this `blog/` folder:
- `index.html`
- `published.html`
- `poetry.html`
- `books.html`
- `world.html`
- `contemplations.html`
- `style.css`

Scroll down, add a commit message (e.g. "Initial site"), and click **Commit changes**

---

## Step 3 — Enable GitHub Pages

1. Go to your repository → **Settings** tab
2. In the left sidebar, click **Pages**
3. Under "Branch", select **main** and leave the folder as `/ (root)`
4. Click **Save**

GitHub will show: *"Your site is live at https://angelaxucx233.github.io"*

It usually takes 1–3 minutes to go live the first time.

---

## Adding New Content

To add a blog post, poem, or book note, simply edit the relevant HTML file and re-upload it (or use the pencil ✏️ edit button directly on GitHub). Each section has clear comments showing exactly where to paste new entries.

For longer pieces, you can create individual HTML files (e.g. `my-essay.html`) using the same header/nav/footer structure, and link to them from the section pages.
